# GitHub Upload Instructions

## Option 1: Upload from GitHub website

1. Create a new repository on GitHub.
2. Name it:

```text
worldcup-travel-demand-prediction
```

3. Do not initialize with README because this folder already includes one.
4. Upload all files and folders from this project folder.
5. Commit with a message such as:

```text
Initial commit: World Cup travel demand prediction project
```

## Option 2: Upload from terminal

Run these commands inside the project folder:

```bash
git init
git add .
git commit -m "Initial commit: World Cup travel demand prediction project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/worldcup-travel-demand-prediction.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.
